# 要件定義書 — 縦スクロールシューティング＋RPG成長要素ゲーム

## 1. プロジェクト概要

ブラウザ上で完結する縦スクロールシューティングゲーム。HTML5 Canvas と Vanilla JavaScript（ES2022+）で実装し、外部画像・音声ファイルを一切使用せず、Canvas 描画 API と Web Audio API のみでネオン調グラフィックと効果音を生成する。RPG 的な「経験値による能力振り直し」とボスから能力を奪取するシステムがコア体験。

---

## 2. 機能要件

### 2.1 画面構成・進行フロー

| ID | 画面名 | 説明 |
|----|--------|------|
| SCR-01 | タイトル画面 | ゲームタイトル、「START」ボタン、クレジット表示 |
| SCR-02 | ステージ選択・強化画面 | ステージ一覧・解放状況、EXP 振り分けUI、装備ボス能力選択 |
| SCR-03 | ゲーム画面 | メインゲームプレイ（縦スクロール） |
| SCR-04 | ポーズ画面 | ゲーム中断・再開・ステージ選択へ戻る |
| SCR-05 | リザルト画面 | クリア/ゲームオーバー後のスコア・EXP 獲得表示 |

**進行フロー:**
```
タイトル → ステージ選択/強化 → ゲームプレイ → リザルト
                ↑___________________________________|
```

### 2.2 ステージ構成

| ID | 要件 |
|----|------|
| STG-01 | ステージは全6面構成 |
| STG-02 | 初期状態ではステージ1のみプレイ可能（ステージ2〜6はロック） |
| STG-03 | ステージN のボスを撃破するとステージN+1 がアンロックされる |
| STG-04 | 各ステージはスクロール区間（雑魚敵ウェーブ）＋ボス戦で構成される |
| STG-05 | 各ステージにはステージ固有の背景色・BGM（手続き生成）・敵配置を持つ |

### 2.3 永続化データ（localStorage）

| ID | 保存項目 | 型 |
|----|----------|----|
| PRS-01 | ステージ解放状況 | `boolean[6]` |
| PRS-02 | 累計獲得 EXP | `number` |
| PRS-03 | 現在の振り分け済みステータス | `Record<StatKey, number>` |
| PRS-04 | 装備中のボス能力 | `number | null`（ボスID） |
| PRS-05 | 各ステージ最高スコア | `number[6]` |
| PRS-06 | 獲得済みボス能力リスト | `boolean[6]` |

### 2.4 経験値（EXP）＆振り直し強化システム

| ID | 要件 |
|----|------|
| EXP-01 | 雑魚敵を撃破すると EXP を獲得する（種別により 10〜50 EXP） |
| EXP-02 | ボスを撃破すると追加 EXP を獲得する（500〜1500 EXP・ステージ依存） |
| EXP-03 | ステージ選択・強化画面で累計 EXP を任意のステータスに割り当て可能 |
| EXP-04 | 振り当て済みポイントはいつでも下げられ、消費 EXP は全額還元される |
| EXP-05 | 一括リセットボタンで全振り分けをリセットし EXP を全額返還できる |
| EXP-06 | 各ステータスには最大レベル上限（Lv.10）を設ける |

**強化可能ステータス一覧:**

| ステータスキー | 説明 | コスト/Lv | 効果単位 |
|----------------|------|-----------|----------|
| `maxHp` | 最大HP | 100 EXP | +20 HP/Lv |
| `moveSpeed` | 移動速度 | 80 EXP | +0.5 px/f/Lv |
| `shotPower` | メインショット威力 | 120 EXP | +5 dmg/Lv |
| `shotRate` | 連射速度 | 100 EXP | -1 f間隔/Lv（最小2f） |
| `bombCount` | ボム初期所持数 | 150 EXP | +1 個/Lv |
| `abilityPower` | ボス能力の威力 | 120 EXP | +10%/Lv |
| `abilityRegen` | 能力ゲージ回復速度 | 80 EXP | +5%/Lv |

### 2.5 ボス固有能力＆獲得システム

| ボスID | ステージ | 能力名 | 説明 |
|--------|----------|--------|------|
| B1 | 1 | 貫通レーザー | 画面縦断の超高威力レーザー |
| B2 | 2 | 追尾ミサイル | 自機を3秒間追尾するミサイルを3発発射 |
| B3 | 3 | 全方位バリア | 3秒間の無敵バリアを展開しつつ当たり判定拡大 |
| B4 | 4 | タイムスロー | 2秒間、敵弾・敵移動を50%スロー |
| B5 | 5 | ギガチャージ | 1.5秒チャージ後、全方向に拡散弾幕を発射 |
| B6 | 6 | 画面爆発 | 全敵・全弾を消去し大ダメージを与える |

| ID | 要件 |
|----|------|
| BOS-01 | ボス撃破時にその能力を獲得し、以降装備可能になる |
| BOS-02 | 同時に装備できるのは1種類のみ（ステージ選択・強化画面で変更可） |
| BOS-03 | 能力発動時は専用ゲージ（0〜100）を消費する |
| BOS-04 | ゲージは時間経過で自動回復する（回復速度はステータス依存） |
| BOS-05 | 発動演出（専用エフェクト・SE）を持つ |

### 2.6 操作方法

| ID | 入力 | 動作 |
|----|------|------|
| INP-01 | 矢印キー / WASD | 自機移動（8方向） |
| INP-02 | スペースキー長押し | メインショット連射 |
| INP-03 | Z キー / J キー | ボス特殊能力発動（ゲージ消費） |
| INP-04 | Shift キー | ボム発動（所持数消費） |
| INP-05 | Escape キー | ポーズ/再開トグル |

### 2.7 グラフィック要件

| ID | 要件 |
|----|------|
| GFX-01 | 外部画像ファイルを使用しない（Canvas 描画 API のみ） |
| GFX-02 | ネオン調スタイル（shadowBlur / グラデーション / 発光エフェクト）を基本とする |
| GFX-03 | パーティクル爆発（敵撃破・ボム発動時） |
| GFX-04 | 画面振動（被弾・爆発時） |
| GFX-05 | ボス能力発動時の専用フラッシュ演出 |
| GFX-06 | 背景は縦スクロールする星/粒子フィールド（ステージ色変化） |

### 2.8 音響要件

| ID | 要件 |
|----|------|
| SND-01 | 外部音声ファイルを使用しない（Web Audio API のみ） |
| SND-02 | ショット音（短い高音パルス） |
| SND-03 | 敵撃破音（爆発クラッシュ音） |
| SND-04 | ボス撃破音（重厚な爆発＋フィードバック音） |
| SND-05 | 能力発動音（ステージごとに異なる特徴的な音） |
| SND-06 | ボム発動音（広域ホワイトノイズバースト） |
| SND-07 | レベルアップ/強化音（上昇アルペジオ） |
| SND-08 | 被弾音（ローピッチインパクト） |
| SND-09 | ゲームBGM（ステージ別・手続き生成のループ） |

## 3. 非機能要件

| ID | 要件 |
|----|------|
| NFR-01 | ターゲット動作環境: Chrome / Firefox / Edge 最新版 |
| NFR-02 | 目標フレームレート: 60 FPS（`requestAnimationFrame` ベース） |
| NFR-03 | Canvas 解像度: 480×720 px（論理解像度）、CSS で任意スケール |
| NFR-04 | 単一 HTML ファイル、またはビルドなし構成（CDN 不使用） |
| NFR-05 | モバイル対応は必須としない（将来拡張として考慮） |

## 4. 受入条件（Acceptance Criteria）

### AC-1: 進行フロー
- [ ] タイトル → ステージ選択 → ゲームプレイ → リザルト → ステージ選択 の一連の遷移が完結する
- [ ] ページリロード後も localStorage からステージ解放状況・EXP・スコアが復元される

### AC-2: ステージアンロック
- [ ] 初期ロード時、ステージ1のみ選択可能でステージ2〜6はロックされている
- [ ] ステージ1ボス撃破後、ステージ2が選択可能になる

### AC-3: EXP・振り直しシステム
- [ ] 敵撃破・ボス撃破時に EXP が加算される
- [ ] 強化画面で EXP を消費してステータスを上げられる
- [ ] ポイントを下げると EXP が全額還元され他のステータスに即再分配できる
- [ ] 一括リセット後は全ての振り分けが解除され、EXP が全額戻る

### AC-4: ボス能力獲得
- [ ] ボス撃破後にその能力が獲得済みリストに追加される
- [ ] 強化画面から装備変更が可能
- [ ] ゲーム中に能力を発動するとゲージが消費され、エフェクトが表示される

### AC-5: 入力
- [ ] 矢印キー/WASD で 8方向移動できる
- [ ] スペース長押しで連射、Z/J で能力発動、Shift でボム発動する

### AC-6: グラフィック・音響
- [ ] 画像ファイル・音声ファイルの読み込みリクエストが発生しない
- [ ] 敵撃破時にパーティクルが飛散する
- [ ] ショット・爆発・能力発動の各 SE が再生される
